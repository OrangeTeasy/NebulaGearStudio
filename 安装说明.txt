Nebula Gear Studio V3.9 安装说明
====================================

一、这是什么
SolidWorks 多形体参数化建模器（宇宙主题界面）：
- 参数化生成基础形体、齿轮、蜗轮蜗杆、弹簧和正 n 面体
- 输出 SolidWorks 零件（SLDPRT），可选导出 STEP / 3MF

二、V3.9 当前修订
- 修复全屏四图模式下，图片黑色底框遮挡黄色中文标语的问题；
- 图片与“建模靠参数，作者靠艺术。”之间增加独立净空；
- 双语文字区域加高，并在每次全屏重排后强制置于图片层上方；
- 保留现有 42pt 艺术中文字体和 Comic Sans MS 英文字体；
- 基础尺寸增加中文＋英文双语参数名；
- 全屏左下方新增“密钥接入 Key”预留输入框，当前版本不保存密钥、不调用网络接口；
- 修复全屏艺术字顶部被底层裁切，以及普通窗口控制台标题遮挡说明文字的问题。
- 扩展全屏白色光圈的连续活动区域：覆盖图片下方留白及中英文，边界停在图片下方约 1 mm。
- 增加 CREO 前端切换入口：按密钥栏状态提示并切换到四种基础模型预览，当前不调用 Creo API 或生成文件。

三、安装要求
1. Windows 64 位系统（Windows 10/11）
2. 已安装并可正常启动 SolidWorks
3. 已配置 SolidWorks 默认零件模板并完成 COM 注册

四、安装步骤
1. 双击 NebulaGearStudio_V3.9_安装程序.exe
2. 选择安装位置（默认 D:\SolidWorks多形体建模器）
3. 点击“安装到本机”
4. 从桌面快捷方式启动

版本：3.9
