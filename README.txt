Nebula Gear Studio V5.0 · 跨版本适配版
================================

功能
----
- 参数化创建长方体、球体、圆柱体、圆锥体和圆台。
- 垫片和轴套由外径、内径、厚度（或高度）直接建模，不读取也不复制 PRTDOT 母版；生成前验证外径大于内径。
- 支持毫米、厘米和米。
- 保存 SOLIDWORKS 零件文件（SLDPRT）。
- 可选导出 STEP 和 3MF。
- 建模模式下拉框直接列出基础形体、正 n 面体及 15 个齿轮、蜗轮蜗杆和弹簧母版。
- 选择母版后点击“设置参数并建模”，在弹窗中逐项按“参数名＋输入框”修改方程值。
- 蜗杆、右旋蜗轮、左旋蜗轮分别是独立的零件入口。
- 生成时先复制安装目录“母版库”中的 SLDPRT，再修改复制件的方程；原始母版不被覆盖。
- 每个母版生成的零件附带 .parameters.txt 参数记录。

母版与方程
----------
15 个 SOLIDWORKS 2024 母版和正 n 面体模板作为安装资源内嵌，安装后释放到程序旁的“母版库”目录，不依赖原作者桌面文件。
参数弹窗读取母版中的全局方程；左侧显示方程名，右侧输入数值或表达式。派生方程也会列出，改动时请遵守 SOLIDWORKS 的方程语法和几何约束。
点击生成后，程序对复制件重建、检查实体并保存 SLDPRT。传动件用于建模和展示；用于制造前仍需校核齿形、配合和强度。

界面与封装图片
--------------
主界面采用宇宙主题、动态星光与流星效果，并使用卡片式参数控制台。
用户提供的 girl-greenhouse.png 作为主界面与安装界面的封装照片，原始文件直接嵌入，不进行重绘、萌化、裁切或调色。
girl-greenhouse.png 生成带透明圆角的 girl-greenhouse-rounded.png，并转换为多尺寸 girl-greenhouse-rounded.ico；主程序、安装器和桌面快捷方式全部使用该圆角图标。
主界面卡片、照片区域、输入框、下拉框和按钮都应用统一圆角；Windows 11 标题栏请求系统圆角样式，同时保留拖动、最小化和关闭功能。
基础尺寸使用“中文＋英文”双语标签，例如“长度 Length、宽度 Width、高度 Height”；直径、内外径和厚度等字段同样采用双语标注。
全屏布局左下方提供“密钥接入 Key”预留输入框，并沿用紫色悬停高亮和轻微放大效果；V5.0 当前不保存密钥，也不连接任何大模型或网络接口。
全屏艺术标语使用透明独立绘制区并预留字体上沿净空，避免照片下方底层裁切行书笔画；普通窗口的控制台标题和说明文字使用独立高度，不再相互覆盖。
全屏标语的白色光圈交互区从四张图片下方约 1 mm 处开始，连续覆盖图片与文字之间的留白、中文和英文；图片本身不触发光圈。
全屏密钥栏右侧提供“转入 CREO”前端入口：密钥为空时显示淡入淡出的“请接入正确的key”；密钥非空时显示“请先补装API Toolkits”并切换到 CREO 前端预览。预览只显示长方体、球体、圆台和正 n 面体，右上角标识改为 CREO；CREO 后端尚未接入，生成按钮保持禁用，不会创建文件。

动态界面
--------
星空亮度保持稳定，不做整屏呼吸闪烁；流星在独立双缓冲背景层中平滑移动，以右上至左下为主并带轻微摇曳。
主建模和浏览按钮在鼠标悬停时显示与界面相配的高亮边框。

建模方式
--------
本程序调用 SOLIDWORKS COM API，不使用 SWP 宏，也不模拟鼠标点击。
基础形体通过 API 创建；母版模式通过 API 读取和修改方程、重建复制件、保存与导出。
如果勾选的 STEP 或 3MF 导出失败，程序会报错并保留已保存的 SLDPRT；此时可检查 SOLIDWORKS 的导出环境后重试。

跨电脑与版本说明
----------------
- 软件本体为 Windows 64 位 .NET Framework 4.x 程序；安装程序已内嵌所需界面资源和 SOLIDWORKS 互操作类型，不依赖开发电脑路径或 SWP 宏。
- 目标电脑仍必须安装可用的 SOLIDWORKS、完成 COM 注册，并配置该版本的默认零件模板；本安装包不包含 SOLIDWORKS 本体或许可证。
- 当前电脑的 SOLIDWORKS 2024 实测可生成基础形体，但其 COM 方程接口对母版写入和空白零件新增方程均返回失败；STEP/3MF 导出也返回错误。齿轮、弹簧与正 n 面体的可改参数功能尚不能视为通过验收。程序现在会在参数未实际写入时停止保存并提示错误，不会把默认模型误报为成功。请在正常启动、无模态窗口的 SOLIDWORKS 会话中进一步排查并在目标电脑实测。
- 基础形体使用当前运行版本的零件模板，不再硬编码 2024 路径。SOLIDWORKS 2024 及更新版本可使用内置的 2024 方程母版；新版本保存后文件将按当前 SOLIDWORKS 版本升级。
- SOLIDWORKS 2023/2022 不能编辑内置的 2024 母版，即使 2023 SP5 能只读查看。请先在有订阅权限的 SOLIDWORKS 2024 中将各 SLDPRT 母版“另存为”2023/2022 版本，并人工处理“不兼容项目”；分别放在安装目录的“母版库\SW2023”或“母版库\SW2022”，文件名须与根目录中的同名母版一致。正 n 面体的 PRTDOT 模板也必须在目标版本中重新制作并保存为“正n面体.PRTDOT”（可尝试先将原模型转换为旧版 SLDPRT，再用旧版创建模板；需人工验证特征和方程）。仅复制或改名不会转换文件版本。
- 找不到对应旧版母版时，软件会给出明确提示，不会把 2024 文件当作可编辑母版。2022/2023 的实际建模与导出尚需在对应版本的电脑上逐项验证；不能仅凭本机的 2024 测试保证全部功能。
- 比 2022 更旧的版本未验证；如需使用，应提供对应版本、可编辑的母版及实机测试环境。
