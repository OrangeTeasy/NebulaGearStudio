# Nebula Gear Studio V5.0 · 跨版本适配版

基于 **SOLIDWORKS COM API** 的参数化机械零件建模工具（宇宙主题桌面界面，C# / WinForms / .NET Framework 4.x）。

## 1. 项目解决什么问题

在 SOLIDWORKS 中手工建立标准机械零件（渐开线齿轮、斜齿轮、蜗杆蜗轮、各类弹簧、正多面体等）步骤繁琐、参数易错。本项目把常用零件的建模封装成「输入尺寸参数 → 一键生成 SLDPRT 零件」的参数化流程，面向教学演示、快速原型与竞赛展示，省去重复建模。

## 2. 主要功能

- **基础形体参数化建模**：长方体、球体、圆柱体、圆锥体、圆台（实测可用）；
- **垫片 / 轴套**：由外径、内径、厚度（高度）公式直建，不读母版，生成前校验外径 > 内径；
- **母版驱动建模**（15 个母版）：直齿轮、圆柱斜齿轮（左/右旋）、直/斜齿圈、锥齿轮、蜗杆、蜗轮（左/右旋）、压缩/拉伸/扭转/截锥弹簧、正 n 面体；
- **方程参数化**：选择母版后在弹窗中逐项修改全局方程；复制母版改方程、不覆盖原母版，并附带 `.parameters.txt` 参数记录；
- **单位切换**：毫米 / 厘米 / 米；
- **输出**：SLDPRT，可选导出 STEP、3MF；
- **宇宙主题界面**：动态星空与流星、卡片式控制台、中英双语标签、圆角与悬停高亮；
- **CREO 前端预览**：界面提供「转入 CREO」入口与密钥输入框（后端尚未接入，属占位）。

## 3. 安装方法

1. 双击 `NebulaGearStudio_V5.0_安装程序.exe`；
2. 选择安装位置（默认 `D:\SolidWorks多形体建模器`，可点「浏览」更改）；
3. 勾选「创建桌面快捷方式 / 开始菜单快捷方式」，点「安装到本机」；
4. 完成后从桌面快捷方式启动。

前置要求（缺一不可）：
- Windows 64 位，.NET Framework 4.x（Win10/11 自带）；
- 已安装并正常启动 SOLIDWORKS 2024（完成 COM 注册，配置默认零件模板）；
- 若为 2022/2023：需先用 2024 将各母版「另存为」对应版本后放入 `母版库\SW2022` / `母版库\SW2023`。

## 4. 使用方法

1. 打开软件，进入宇宙主题主界面；
2. 在「建模模式」下拉框选择要生成的形体 / 零件；
3. 基础形体：直接输入尺寸（可切 mm / cm / m）后点「启动建模」；
   齿轮 / 蜗轮蜗杆 / 弹簧 / 正 n 面体：点「设置参数并建模」，在弹窗中逐项填写参数；
4. 设置输出目录（默认 `桌面\SolidWorks零件`），勾选是否导出 STEP / 3MF；
5. 点击建模，程序调用 SOLIDWORKS 生成并保存零件。

## 5. 输入输出示例

**示例 1 · 长方体**
- 输入：建模模式=长方体，长度=100 mm，宽度=50 mm，高度=30 mm
- 输出：`桌面\SolidWorks零件\长方体_20261022_143000_123.SLDPRT`

**示例 2 · 直齿轮**
- 输入：建模模式=直齿轮，模数=2 mm，齿数=20，压力角=20°，齿宽=15 mm，孔径=10 mm
- 输出：`桌面\SolidWorks零件\齿轮_m2_z20_20261022_143001_456.SLDPRT` + 同名 `.parameters.txt`（记录本次参数）

**示例 3 · 蜗杆**
- 输入：建模模式=蜗杆，模数=2 mm，压力角=20°，头数=2，有效长度=40 mm，直径系数 q=10
- 输出：`桌面\SolidWorks零件\蜗杆_m2_头数2_20261022_143002_789.SLDPRT`

## 已知限制

- 齿轮 / 弹簧 / 正 n 面体的「方程写入」及 STEP / 3MF 导出在当前 SOLIDWORKS 2024 实测返回失败，尚未通过验收；目前仅基础形体（长方体 / 球体 / 圆柱 / 圆锥 / 圆台）实测可用。
- 齿轮 / 蜗杆 / 蜗轮为结构 / 外观级工程近似，未做滚刀包络、齿面修形、侧隙与强度校核，不可直接用于制造。
- CREO 后端尚未接入，「密钥接入 Key」输入框不保存、不联网，仅前端演示。
